# OSMINOG — премиальный лендинг веб-студии

Кастомная вёрстка (HTML/CSS/JS, без конструкторов). Тёмная премиальная тема, адаптив,
готов под контекстную рекламу. Одна кодовая база → несколько посадочных под ниши.

## Структура
```
template.html          # единый шаблон с плейсхолдерами {{...}}
build.py               # генерирует посадочные из template.html + конфига NICHES
index.html             # основная посадочная            (генерируется)
kliniki/index.html     # посадочная под клиники          (генерируется)
magaziny/index.html    # посадочная под интернет-магазины (генерируется)
assets/
  css/style.css        # дизайн-система
  js/main.js           # интерактив (меню, reveal, FAQ, видео, форма)
  team/*.webp          # фото команды (прозрачные, на тёмном)
  logos/*.webp         # логотипы клиентов
  video/*              # видеоотзыв + постер
.nojekyll              # для GitHub Pages
```

## Как пересобрать / добавить нишу
1. Правишь контент в `template.html` (общие блоки для всех посадочных).
2. Заголовки/подзаголовки/мета под нишу — в `build.py`, список `NICHES`.
   Чтобы добавить новую нишу, скопируй блок в `NICHES` (out, root="../", h1, lead, meta и т.д.).
3. Запусти:
   ```bash
   python build.py
   ```
   Пересоберёт `index.html` и все `<ниша>/index.html`.

Каждая ниша живёт на своём URL → в Яндекс.Директе группа объявлений ведёт на свой адрес.

## Форма заявки
Сайт статический (без бэкенда). Сейчас форма формирует письмо на `info@osminog.biz`
через почтовый клиент (mailto) + рядом прямые кнопки: телефон и Telegram
(`@Osminog_Project`) — основной канал заявок.
Для приёма заявок прямо на сайт можно подключить бэкенд (Formspree / Telegram-бот) —
точка входа: обработчик `#lead-form` в `assets/js/main.js`.
