# Приём заявок с формы → Битрикс24 + Telegram

Сайт статический (GitHub Pages), поэтому заявки отправляются через маленький
бесплатный обработчик — **Cloudflare Worker** (`worker.js`). Он принимает данные
формы, создаёт лид в Битрикс24 и шлёт уведомление в Telegram-группу.
Токены хранятся на сервере (в переменных Worker), в коде сайта их нет.

## Что нужно собрать

1. **Входящий вебхук Битрикс24** (у команды OSMINOG):
   Битрикс24 → «Разработчикам» → «Другое» → «Входящий вебхук» →
   отметить право **CRM (crm)** → сохранить → скопировать URL вида
   `https://XXXX.bitrix24.ru/rest/1/ТОКЕН/`

2. **Telegram-бот и группа:**
   - в Telegram написать @BotFather → `/newbot` → получить **токен**;
   - создать группу для заявок, добавить туда бота и сделать его администратором;
   - узнать **id группы**: добавить в группу @getmyid_bot (или @RawDataBot),
     он покажет отрицательный id вида `-1001234567890`.

## Развёртывание Worker (5 минут)

1. Зайти на dash.cloudflare.com (бесплатный аккаунт) → Workers & Pages →
   Create → Worker → вставить код из `worker.js` → Deploy.
2. В Settings → Variables добавить переменные:
   - `BITRIX_WEBHOOK` = URL входящего вебхука Битрикс24
   - `TG_TOKEN` = токен бота
   - `TG_CHAT` = id группы (напр. `-1001234567890`)
   - `ALLOW_ORIGIN` = `https://coldinfinity696969-byte.github.io` (или домен сайта)
3. Скопировать адрес воркера (вида `https://osminog-lead.ВАШ.workers.dev`).

## Подключение к сайту

В форме на сайте выставить адрес воркера — в `template.html` у тега формы:
```html
<form ... data-endpoint="https://osminog-lead.ВАШ.workers.dev">
```
Пересобрать (`python build.py`) и запушить. Всё — заявки полетят в Битрикс24 и в телегу.
Пока `data-endpoint` пустой, форма работает в резервном режиме (открывает письмо на info@osminog.biz).
